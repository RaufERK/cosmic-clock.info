# Сценарий

Короткая реклама с записи экрана. Зритель видит, как **пользуются живым сайтом** в телефонном кадре. Между действиями — крупный текст: адрес и одна строка про скорость и циклы.

Возраста считаем на **18 августа 2026**.

## Хронометраж

Цель **20–35 секунд** на основной ролик. Три карточки (Laura, Daniel, Clara). Если ещё спокойно по темпу — добавить Lucas.

## Картинка (одна для EN / ES / PT)

1. **Открытие на телефонном кадре**, сайт уже открыт (гость или пустой список — не админка, не логин). Адрес пока не главный герой; его даст первый титр.
2. **Титр A** (крупно): `cosmic-clock.info`  
   Под ним одна строка (см. [overlay-copy.md](overlay-copy.md)). Держать ~2 секунды.
3. **Добавить часы.** Ввести **Laura**, дата **12 March 1958**. Имя не гнать: должно читаться. Далее / готово, пока **форма не станет часами**. На готовом циферблате держать ~2 секунды (стрелки видны).
4. **Добавить часы.** **Daniel**, **4 November 1955**. То же: имя читается, затем превращение. Двое часов — уже пара.
5. **Добавить часы.** **Clara**, **20 June 1984**. Третье превращение = «и циклы близких».
6. По желанию: **Lucas**, **8 September 1987**.
7. **Держать семейство часов** в кадре.
8. **Титр B:** снова адрес + финальная строка (`See your cycles — and theirs.` / эквивалент на языке версии).
9. Конец на адресе. Без логина, пароля, настроек.

## Что должно быть видно

- **Имя**, пока его печатают (имена — это и есть «локализация» для LatAm).
- **Дату**, пока её выбирают (месяц + день + год).
- Движение **форма → часы**. Это демо продукта. Срезать рано — в ролике не будет доказательства.
- После двух-трёх карточек: **разные положения стрелок**. Даты выбраны так, чтобы циферблаты не копировали друг друга.

## Что не попадает в кадр

- Гостевая карточка **The Summit Lighthouse / 1958-08-07** (удалить до дубля или начать с состояния, где сид уже сброшен).
- Вход в аккаунт, ошибки, режим перестановки/замок, админка.
- Панель кода DevTools, строка меню ноутбука, обои рабочего стола. Пишем **только** телефонный вьюпорт (см. [recording-setup.md](recording-setup.md)).

## Куда ставить титры

- Сверху или по центру, **крупно**. Одна мысль на карточку.
- Во время превращения не закрывать циферблат.
- Пока печатаем — титр можно приглушить или оставить тонкой полоской сверху; на финальной паузе с часами — снова крупнее.

## Языковые версии

| Версия | Интерфейс | Титры | Имена в форме |
|--------|-----------|-------|----------------|
| Основная (EN / LatAm) | English | английские | Laura, Daniel, Clara |
| Испанская | та же картинка или UI `es` | испанские | те же имена |
| Португальская (Бразилия) | та же картинка или UI `pt` | португальские | те же имена |
| Русская | свой проход, UI `ru` | русские | те же даты; имена Laura/Daniel/Clara тоже ок, или Лариса / Даниил / Клара |

Самый дешёвый путь: **одна запись с английским UI**, три дорожки титров (EN, ES, PT). В русском интерфейсе другие названия месяцев — снимать отдельно.

## Тайминг (основной ролик)

| Время (ориентир) | Действие | Титр |
|------------------|----------|------|
| 0:00–0:03 | Телефон + сайт | `cosmic-clock.info` + короткий слоган |
| 0:03–0:12 | Заполнить **Laura** → появляются часы | нет или слабый URL |
| 0:12–0:20 | Заполнить **Daniel** → вторые часы | нет |
| 0:20–0:28 | Заполнить **Clara** → третьи часы | нет |
| 0:28–0:35 | Семейство часов | URL + «свои циклы и циклы близких» / EN-эквивалент |

Время — ориентир. Чистое превращение важнее попадания в секунду.
