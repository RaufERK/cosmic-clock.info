# Аудитория — почему ролик выглядит так

Цифры ниже — **просмотры за последние 365 дней** (аналитика канала, по ней зафиксирован сценарий). Отсюда имена, возраста, языки и даты «папа / мама / дети» — не для красоты.

## Регионы

| Регион | Доля | Что это значит для ролика |
|--------|------:|---------------------------|
| США | 39.6% | Главный рынок. Интерфейс English. Имена должны выглядеть нормально в США. |
| Мексика | 7.4% | Испанский; те же латинские имена, без англо-only (Liam, Noah). |
| Колумбия | 4.3% | Как Мексика. |
| Бразилия | 4.1% | Португальский; имена **без** диакритики (`Sofia`, не `Sofía` / `João`). |
| Канада | 2.7% | Тот же английский ролик, что для США. |

Рамка — Северная + Латинская Америка. Одна картинка, одна семья, три языка титров (EN / ES / PT). Не снимать «только американскую» или «только латино» семью.

## Возраст и пол

| Срез | Доля |
|------|------:|
| Женщины | 62.6% |
| Мужчины | 37.4% |
| 13–17 | 0.7% |
| 18–24 | 0% |
| 25–34 | 4.2% |
| 35–44 | 8.6% |
| 45–54 | 12.0% |
| 55–64 | 22.7% |
| 65+ | **51.8%** |

**Ядро зрителя:** женщина примерно **60–75**, в основном США, также Мексика / Колумбия / Бразилия.

Следствия:

1. **Первая карточка — мама (Laura).** Это зрительница. Не открывать с ребёнка.
2. **«Дети» — взрослые ~38–42**, не детский сад. Именно такие дети у 68-летней матери. Малыш в кадре промахнётся мимо аудитории.
3. **Внук** для 65+ эмоционально верен, но в брифе были папа / мама / дети, а 13–17 как *зрители* почти отсутствуют. Внука не ставить, пока не понадобится отдельный ролик про три поколения.
4. Не ставить «молодую семью 30 лет». Это 4% просмотров.

## Языки (субтитры канала)

| Язык | Доля |
|------|------:|
| Без субтитров | 88.1% |
| английский | 8.5% |
| испанский | 0.9% |
| английский (США) | 0.6% |
| португальский | 0.4% |

Большинство смотрит **без субтитров**. Титр должен работать как **крупный текст на картинке**, не как мелкие субтитры абзацем.

- **Основной ролик:** английские титры + английский интерфейс. Испано- и португалоязычные всё равно читают **Laura / Daniel / Clara**.
- **Доп. версии:** та же картинка, титры заменить на испанские или португальские (дёшево).
- **Русский:** своя съёмка (или отдельный проход титров). Не мешать в англо-латино картинку.

## Связь с продуктом

Гостевой сид на сайте — **1958-08-07** (The Summit Lighthouse). Кривая возраста (65+) совпадает с этой духовной аудиторией. Ролик должен ощущаться как **их** семейные часы, не как демо приложения для Gen-Z.

В записи **не** вводить `1958-08-07`. Выглядит как забытый пример.
